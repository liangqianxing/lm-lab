# 学习 / 实验记录模板

复制到 `runs/<实验名>/record.md` 后填写。空栏表示尚未记录，不代表测量为零；不要预填性能提升或模型能力。手算期望、教学示例与实测结果分开标注。

## 问题与假设

- 日期、任务或里程碑：
- 状态（未开始 / 进行中 / 已验证）：
- 想回答的问题：
- 可验证的假设：
- 成功或否定假设的验收条件：
- 样本类型（手写教学示例 / 真实数据）：

## 代码与运行

- 代码版本（`git rev-parse HEAD`；首次提交前写“尚无提交”）：
- 工作区状态（`git status --short`；未提交修改的 diff/快照位置）：
- Python、依赖版本：
- 完整运行命令及工作目录：
- 配置（模型、tokenizer、词表、batch、序列长度、预算等）：
- 随机种子及确定性设置（没有随机过程时明确写“无”）：
- 数据来源、许可、版本、指纹、样本数与划分：
- 硬件（CPU、内存、GPU/显存；未使用 GPU 时注明）：

## 原始证据

- 原始输出、日志、测量 JSON 或检查点路径：
- 检查命令、退出码及失败摘要：
- 计时方法、预热、同步、重复次数与每次结果：
- 正确性对照的来源、输入、误差容限：
- 评测数据泄漏/跨划分重复检查（不适用时说明原因）：

## 结果与解释

- 实际观测（引用原始输出，不以手算期望代替）：
- 与假设/对照的关系：
- 波动、失败案例与数值稳定性问题：
- 局限（样本、硬件、预算、实现、外推等）：
- 下一步及未解决问题：
- 是否满足里程碑验收、支持该状态的证据路径：
